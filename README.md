# 無邊際白板 Infinite Whiteboard

![無邊際白板操作介面](UI.png)

一款以單一 HTML 檔案實作的無邊際白板，適合課堂講解、概念整理、腦力激盪與小組討論。可在電腦、平板、手機及教室電子白板上使用，不需要帳號、後端服務或建置流程。

**線上使用：**[https://harmony-h.github.io/infinite-whiteboard-group3/](https://harmony-h.github.io/infinite-whiteboard-group3/)

## 功能

- **繪圖：**自由筆刷、橡皮擦、筆畫橡皮擦、直線、長方形、正方形、圓形及橢圓形。
- **筆觸設定：**自訂顏色、快速色票、1–60 px 粗細，以及筆跡平滑開關。
- **便條貼：**加入便條、選擇四種顏色、編輯文字、拖曳移動及調整大小；便條提供編輯、確認和刪除控制。
- **物件操作：**選取並移動筆畫、圖形或便條；可刪除所選項目，或清除整張白板。
- **無邊際畫布：**以世界座標保存內容，可平移、縮放並回到中心；縮放範圍為 10%–500%。
- **復原與重做：**支援繪圖、刪除、移動、便條編輯等操作。
- **保存與交換：**自動儲存在目前瀏覽器，並可匯出白板 JSON、匯入 JSON 或下載畫布 PNG。
- **AI 對話（選用）：**可連接 OpenAI 官方 API 或長庚 CGU Gateway，載入可用模型並以 LaTeX 輸入及顯示公式。
- **觸控支援：**觸控筆或單指繪圖，雙指平移和縮放；提供手機和平板版工具列配置。

## 操作

| 動作 | 操作方式 |
| --- | --- |
| 繪圖或使用目前工具 | 在畫布拖曳；觸控裝置以單指拖曳 |
| 平移畫布 | 選擇平移工具後拖曳，或按住空白鍵並拖曳；滑鼠中鍵或右鍵拖曳也可平移 |
| 縮放畫布 | 滑鼠滾輪，或在觸控裝置上雙指張合 |
| 選取物件 | 切換到選擇工具後點選物件，再拖曳移動 |
| 調整便條大小 | 拖曳便條右下角控制點；最小邊長為 60 px |
| 編輯便條 | 使用便條上的編輯控制；按 `Ctrl/⌘+Enter` 確認編輯 |
| 返回上一步 | 工具列按鈕或 `Ctrl/⌘+Z` |
| 重做 | 工具列按鈕、`Ctrl/⌘+Shift+Z` 或 `Ctrl+Y` |
| 刪除所選物件 | 工具列按鈕、`Delete` 或 `Backspace` |

快捷鍵在文字輸入欄位編輯時不會攔截輸入。繪製正方形時，拖曳距離較長的方向決定邊長。

## 保存與匯出

白板內容與畫布檢視設定會自動保存到瀏覽器的 `localStorage`。資料留在目前的瀏覽器和裝置，不會同步至其他裝置；清除瀏覽器網站資料也會移除自動保存的內容。需要備份或移轉時，請使用工具列的匯出選單下載 JSON，並在另一個裝置使用匯入按鈕載入。匯出 PNG 可保存目前畫布畫面作為圖片。

JSON 檔保存可繼續編輯的筆畫、圖形、便條及畫布檢視位置；PNG 是圖片，無法還原成可編輯物件。匯入 JSON 會以匯入內容取代目前白板。

## AI 對話

1. 開啟工具列的「AI 對話」，選擇 OpenAI 官方或長庚 CGU Gateway。
2. 輸入對應服務提供的 API key，按「套用金鑰」。兩種服務的金鑰不能互換。
3. 按「載入模型」，再從清單選擇此金鑰可使用的模型。
4. 輸入訊息後按 Enter 或「傳送」；按 `Shift+Enter` 可換行。公式可使用 LaTeX。

API key 只保存在頁面記憶體，重新整理或關閉頁面後會清除，也不會寫入自動保存或匯出檔。對話訊息會由瀏覽器直接傳送至所選 API；白板內容不會自動附加。OpenAI 使用 `https://api.openai.com/v1` 的 `/models` 與 `/chat/completions`；CGU 使用 `https://air.cgu.edu.tw/cgullmapi/v1` 的 `/models` 與 `/responses`。可用模型依服務端權限而定。

公式排版使用 MathJax 3.2.2（jsDelivr CDN）。AI 對話和公式排版需要網路；如果 MathJax 無法載入，公式會以原始 LaTeX 文字顯示。

## 本機執行

可在瀏覽器直接開啟 `index.html` 使用白板基本功能。AI API 請求可能受 `file://` 跨來源限制，建議透過本機 HTTP 伺服器開啟。若已安裝 Node.js，可在專案資料夾執行：

```powershell
npx --yes http-server . -p 8000
```

接著瀏覽 `http://localhost:8000/`。也可以使用其他靜態檔案伺服器。若 AI 顯示 `Failed to fetch`，請確認網路、防火牆、VPN 或瀏覽器擴充功能是否阻擋 API 請求；HTTP 401 則通常表示金鑰無效或不具權限。
